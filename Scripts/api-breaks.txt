# Breaking changes of the public plugin API (AFMKernel, AFMContracts) that were made on purpose.
# Read by Scripts/api-check.sh (the `api` gate of Scripts/check.sh), which fails on every break
# that is not listed here and on every line here that matches no break.
#
# Each acknowledged break is the digester's line exactly as the gate printed it, under a
# `# reason:` comment saying why the break is worth what it costs plugins; a blank line ends the
# reason. Once the change is on main, the line matches no break any more: delete it then.
#
# Example:
#   # reason: the old name said "path" for what is a URL; renamed before any outside plugin exists
#   AFMKernel: Func FileSystemProvider.list(path:) has been renamed to Func list(at:)

# reason: Swift 6 migration. File systems, readers, writers, settings stores, job monitors and the user
# interaction are used from several threads (their documentation always said so); the protocols now say it to
# the compiler, so a plugin type that is not safe to share fails to build instead of racing.
AFMKernel: Protocol FileReader has generic signature change from <Self : AnyObject> to <Self : AnyObject, Self : Swift.Sendable>
AFMKernel: Protocol FileSystemProvider has generic signature change from <Self : AnyObject> to <Self : AnyObject, Self : Swift.Sendable>
AFMKernel: Protocol FileWriter has generic signature change from <Self : AnyObject> to <Self : AnyObject, Self : Swift.Sendable>
AFMKernel: Protocol JobMonitor has generic signature change from <Self : AnyObject> to <Self : AnyObject, Self : Swift.Sendable>
AFMKernel: Protocol SettingsStore has generic signature change from <Self : AnyObject> to <Self : AnyObject, Self : Swift.Sendable>
AFMKernel: Protocol UserInteraction has generic signature change from <Self : AnyObject> to <Self : AnyObject, Self : Swift.Sendable>
AFMKernel: Protocol FileReader has added inherited protocol Sendable
AFMKernel: Protocol FileReader has added inherited protocol SendableMetatype
AFMKernel: Protocol FileSystemProvider has added inherited protocol Sendable
AFMKernel: Protocol FileSystemProvider has added inherited protocol SendableMetatype
AFMKernel: Protocol FileWriter has added inherited protocol Sendable
AFMKernel: Protocol FileWriter has added inherited protocol SendableMetatype
AFMKernel: Protocol JobMonitor has added inherited protocol Sendable
AFMKernel: Protocol JobMonitor has added inherited protocol SendableMetatype
AFMKernel: Protocol SettingsStore has added inherited protocol Sendable
AFMKernel: Protocol SettingsStore has added inherited protocol SendableMetatype
AFMKernel: Protocol UserInteraction has added inherited protocol Sendable
AFMKernel: Protocol UserInteraction has added inherited protocol SendableMetatype

# reason: Swift 6 migration. These calls hand values from one thread to another (a background answer, a job's
# result, the elements of a parallel map), so the values must be Sendable; the compiler now checks it.
AFMKernel: Func BlockingCalls.answer(from:to:sharing:cancellation:_:) has generic signature change from <Answer> to <Answer where Answer : Swift.Sendable>
AFMKernel: Func BlockingCalls.answer(from:to:sharing:cancellation:_:then:) has generic signature change from <Answer> to <Answer where Answer : Swift.Sendable>
AFMKernel: Func JobMonitor.ask(_:) has generic signature change from <Self, Answer where Self : AFMKernel.JobMonitor> to <Self, Answer where Self : AFMKernel.JobMonitor, Answer : Swift.Sendable>
AFMKernel: Func JobService.run(title:work:completion:) has generic signature change from <Self, Result where Self : AFMKernel.JobService> to <Self, Result where Self : AFMKernel.JobService, Result : Swift.Sendable>
AFMKernel: Func Kernel.askUser(_:) has generic signature change from <Answer> to <Answer where Answer : Swift.Sendable>
AFMKernel: Func Parallel.map(_:serialBelow:_:) has generic signature change from <Element, Result> to <Element, Result where Element : Swift.Sendable, Result : Swift.Sendable>

# reason: Swift 6 migration. The watch token is released on whatever thread lets go of it, so it must be
# Sendable (`WatchToken` is `AnyObject & Sendable`); `onChange` is documented to run on the main thread and is
# now @MainActor.
AFMKernel: Func FileSystemProvider.watch(_:onChange:) has return type change from Swift.AnyObject? to (any AFMKernel.WatchToken)?
AFMKernel: Func FileSystemProvider.watch(_:recursively:onChange:) has return type change from Swift.AnyObject? to (any AFMKernel.WatchToken)?
