## Decisions

1. **Several sources onto one target name** (F006): the job's own output is never overwritten by a rule ("Overwrite
   all", "older", "larger", …, whether preset or answered "for all" in this very question). The later file arrives as
   `name (2).ext`. With "Skip all" it is skipped, with the auto-rename rules it is handled as usual. In "Ask" mode the
   Overwrite question still comes, and "Overwrite" for that one file is honoured.
2. **Special files** (F007): pipes, devices and sockets are skipped with a reported error everywhere, also
   local-to-local; nodes are not recreated (the provider interface has no call for it). A link to one is copied as a
   link where links are copied. A move within one file system still renames them.
3. **Mount points** (F012): Delete and Move ask at every folder that lies on another device than its parent, also at a
   top-level source. Buttons: Skip (default), Delete/Move its contents, All Volumes, Cancel. Without a delegate answer
   the default is Skip. A skipped volume counts as a failure of the job (the folder above stays). Copy still descends.
4. **Timestamp tolerance** (F023): 1 ms on APFS (rounding of `Date`), 1 s on HFS+, 2 s on any other local file system,
   on shares and on servers/archives; unknown counts as 2 s.
5. **`755` vs `4755`** (F028/F076): behaviour now matches `chmod`. Any octal mode is absolute: `755` clears set-user-ID,
   set-group-ID and sticky. Letters (`rwxr-xr-x`) and clauses keep them. The dialog's note says so.
6. **Recurse with untouched permissions** (F028): a question "give the permissions NNN to everything inside as well?"
   (Apply / Back) instead of a silent return.
7. **Locked item with "Locked: unchanged"** (F064): reported as a failure and left as it is.
8. **Huge selections on the clipboard** (F002/F004): no lazy scheme works for files (measured; details in cross-request
   7). Above 1000 files the user chooses: "For This Program" (default, instant; other programs get the paths as text) or
   "Also for Other Programs" (blocks for the time the system takes) or Cancel.
9. **Cut, then Paste into the same folder**: nothing happens and the files stay cut (before, the cut was forgotten).
10. **Streamed permissions** (F053): special bits are always dropped across file systems; the umask is applied only when
    the destination is the local disk (packing into an archive or uploading keeps group/other bits).
11. **Stale temporary files** (F051): only names of the exact form `.afm-<UUID>.tmp`, plain files, with both
    modification and status-change time older than 24 hours, in the job's top-level target folder, local disks only,
    once per folder and run.
12. **Hard link of the source as target**: refused with "You cannot copy a file to itself!", as `cp` and `mv` do.
13. **Depth** (F019): folders nested deeper than 1024 levels are reported and not entered.
14. **Abort** also sets the job's cancellation flag (F046), so in-flight parallel copies stop instead of finishing their
    current file.
15. **Names the comment file cannot hold** (F068): refused with a message rather than written in a form that reads back
    as another name.
16. **Log flush at quit** (F027): waits at most 2 seconds on the main thread.
17. **A list of files as target** (F026): F5/F6 propose the name alone (as Shift+F5 does); Paste into a list is refused
    with a message.
