live, the INI rules, every documented section and key of `wincmd.ini` and `wcx_ftp.ini`, the small file formats (button

`totalcmd64.exe` and the messages a running instance accepts, the environment variables TC defines and expands, and what
is saved when. The behaviour that the settings control is described in the chapters named in each row; this chapter is
the storage reference.

## Conventions

- Keys are in `[Configuration]` of `wincmd.ini` unless another section is named. Section and key names are
  case-insensitive (§2.1).
- **Default** is the value the help documents (it writes `Key=default`). "e.g." marks an example value from the help,
  not a default. "—" means that no default is documented and the key is absent from a fresh ini. A default in
  parentheses is derived from another key or from the system.
- **Set in** names the place that writes the key: `13 › <page>: *control*` is a control on that Options page (leaf page
  names as in chapter 13), `14` an editor of chapter 14, another chapter number (e.g. `09 › Find Files`) a dialog or
  tool that remembers the value, `TC` a value the program writes by itself, `none` an ini-only key that only the user
  writes.
- "A used ini held …" reports a value seen in a real `wincmd.ini` after some days of use; it shows the storage format,
  not a default.
- The help writes `totalcmd.exe`; the 64-bit program is `totalcmd64.exe` with the same switches.

### 1.3 How the location of `wincmd.ini` and `wcx_ftp.ini` is chosen

```text
locate(kind):                       # kind = MAIN (wincmd.ini) or FTP (wcx_ftp.ini)
    if kind==MAIN and "/i=<file>" on the command line:  return <file>
    if kind==FTP  and "/f=<file>" on the command line:  return <file>
    progIni = <program dir>\wincmd.ini
    u = progIni exists ? progIni[Configuration].UseIniInProgramDir : 0
    want = (kind==MAIN) ? (u & 1) : (u & 2)
    if want and (u & 4):            return <program dir>\<name>   # bit 4 overrides the registry
    reg = registry HKCU or HKLM \SOFTWARE\Ghisler\Total Commander,
          text value IniFileName (MAIN) / FtpIniName (FTP)
    if reg set:                     return reg
    if want:                        return <program dir>\<name>
    if kind==MAIN and <Windows dir>\wincmd.ini exists:  return it  # legacy location
    return %APPDATA%\GHISLER\<name>
```

- **Precedence** (help): `/i=` and `/f=` win over the registry values; `UseIniInProgramDir` bit 4 overrides the registry
  but not the command line. The last two steps come from the change log; TC also falls back to `%APPDATA%\GHISLER` when
  the Windows directory is write-protected.
- **Registry.** The key can exist under `HKEY_CURRENT_USER` or `HKEY_LOCAL_MACHINE`; the help does not say which wins.
  The installer copies `IniFileName` and `FtpIniName` from HKLM to HKCU when they are missing there, which suggests that
  HKCU is read first (unverified).
- **`UseIniInProgramDir`** is read **only** from a `wincmd.ini` in the program directory, from that file itself;
  `RedirectSection` does not affect it (§1.6).
- **Installer.** It writes the chosen location to the registry. Interactively the page _Change ini file location_ offers
  Windows directory (greyed), Program directory (greyed), **Application data (user-specific application data)**
  (selected), Documents and Settings (user-specific documents), User-defined directory, and
  `[x] Set this location for all users on this system` (01 › Change ini file location). Its switches `I"dir"` (`.\` =
  program directory), `I1…` (for all users) and `I0` (write nothing to the registry) do the same unattended (01 ›
  Installer command-line parameters).
- **Changing it later:** the add-on `inireloc.exe` (ghisler.com, Addons), `/i=`, `/f=` or `UseIniInProgramDir`.
- **Where to see it:** Help › About Total Commander lists both paths under "Settings files:" (12 › About box);
  `%COMMANDER_INI%` and `%COMMANDER_INI_PATH%` hold the main file (§9.3).
- **Relative names** in `/i=` / `/f=` (the help's example is `/I=Miller.ini`): resolution not documented.
- **Propagation.** A restart through `cm_Exit 1` passes `/N` plus the previous `/i=` and `/f=` to the new instance; a
  search in a separate process (Alt+Shift+F7) also receives the `/i=` location.
- Without `FtpIniName` and `/f=`, `wcx_ftp.ini` is next to `wincmd.ini` (observed).

### 1.5 Write test, read-only and shared ini files

- **Write test.** `Test=` is written internally to check that the ini can be written; if not, TC shows an error message.
  `Firstmnu=` serves the same purpose without the message. Values seen: `firstmnu=2810` (fresh Windows 11 ini),
  `firstmnu=3002` and `test=110` (a used ini); the values carry no documented meaning.
- **Read-only main ini** (e.g. a shared, centrally managed file):
  - redirect the user-changeable sections with `AlternateUserIni=` to a writable file (§1.6);
  - to **deactivate** a section, such as one of the histories, redirect it to a read-only file;
  - TC keeps working: the custom font and icon size are saved through `AlternateUserIni`; 64-bit plugins still load
    although the `[…64]` index sections cannot be written; hotkeys are saved when `[Shortcuts]` is redirected.
- **Write failures** are reported: for `wcx_ftp.ini` when deleting, dragging, creating a URL connection or changing
  encryption; for `usercmd.ini` on Delete / Rename / Copy; for a `.bar` file TC offers to copy it to the user profile or
  to change its permissions (14 › Bar files and the default bar).
- **Thumbnail database:** only one user can open it at a time; it must not be shared between users.
- **`RestrictInterface`** (§4.29) can also be set in the registry ("in wincmd.ini or registry"); the value name and key
  are not documented further, presumably the same name under `…\Ghisler\Total Commander` (unverified).
- **Several instances** share one ini. Saving a button bar makes the other running instances reload it. TC also informs
  the other TC windows about changes of the frequently used directories (by `SendMessageTimeout`, so that one hanging
  instance cannot block the others). No other cross-instance synchronisation is documented; presumably an instance that
  exits later overwrites what an earlier one saved on exit (unverified).

### 1.6 Several ini files: `AlternateUserIni` and `RedirectSection`

| Mechanism                     | Where                              | Values       | Effect                                                                                                                                                                                                                                                                      |
| ----------------------------- | ---------------------------------- | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AlternateUserIni=<file.ini>` | `[Configuration]` of the main ini  | File name    | Every user-changeable section goes to that file, **except** `[Configuration]`, `[Layout]`, `[Packer]`, `[Confirmation]`, `[Extensions]`, `[Associations]`, `[Shortcuts]`, `[ShortcutsWin]`, `[PackerPlugins]`, `[FileSystemPlugins]`, `[ListerPlugins]`, `[ContentPlugins]` |
| `RedirectSection=`            | Inside any section of the main ini | `0`          | Never redirect this section, even if `AlternateUserIni` would                                                                                                                                                                                                               |
|                               |                                    | `1`          | Redirect it to the `AlternateUserIni` file (also works for the excepted sections)                                                                                                                                                                                           |
|                               |                                    | `<file.ini>` | Redirect it to that file                                                                                                                                                                                                                                                    |

```text
fileForSection(name):
    r = MAIN[name].RedirectSection            # read from the MAIN ini only
    if r == "0":  return MAIN
    if r == "1":  return AlternateUserIni     # as set in MAIN [Configuration]
    if r != "":   return r
    if MAIN[Configuration].AlternateUserIni != "" and name not in EXCEPTED:
                  return AlternateUserIni
    return MAIN
```

- **All redirections must be in the main (first) ini file.** Redirections inside secondary files are ignored, and so are
  redirections in `wcx_ftp.ini`.
- `RedirectSection` inside `[Configuration]` moves **all** keys of that section to the other file, except
  `AlternateUserIni` and `UseIniInProgramDir`, which are always read from the main file.
- Typical uses: a read-only main ini; volatile data (directory and command-line histories) in a separate file that can
  be deleted regularly; a section disabled by pointing it at a read-only file.
- The name `RedirectSection` is reserved: the Misc page refuses to create an alias with that name and does not list one.

## 2. INI rules

### 2.1 Access semantics

TC reads and writes its ini files through the Windows profile API (`GetPrivateProfileString` and related functions). A
compatible implementation must reproduce that API's behaviour:

| Rule              | Detail                                                                                                                                                                                                                                        |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Case              | Section and key names are **case-insensitive**. Real files write `activepanelcolor=`, `test=`, `firstmnu=` where the help writes `ActivePanelColor`, `Test`, `Firstmnu`. Match case-insensitively; keep the existing spelling when rewriting. |
| Names with spaces | Allowed: `Aligned extension`, `negative Sortorder`, section `[Command line history]`, resolution sections such as `[3456x1896 (10x20)]`.                                                                                                      |
| Duplicates        | The first occurrence wins (also for internal associations).                                                                                                                                                                                   |
| Quotes            | The API strips **one** pair of quotes that encloses a whole value. A value that must itself start and end with `"` is written with an extra pair: `Filter1_open=""%windir%\notepad.exe" "%1""`.                                               |
| Comments          | The help defines no comment syntax and TC's files contain none. Preserve unknown lines unchanged.                                                                                                                                             |
| Line ends         | CRLF in every real file (`wincmd.ini`, `.bar`, `descript.ion`).                                                                                                                                                                               |
| Section size      | Windows limits a section to 64 KB in ANSI files, 128 KB in UTF-16 files (relevant for a large `[DirMenu]`).                                                                                                                                   |
| Absent key        | Means "use the default". Many defaults depend on another key (e.g. `CountMarkedInDialog` takes `CountMarked`).                                                                                                                                |

### 2.2 Encoding

- Valid encodings: **ANSI** (system code page) or **UTF-16 LE with BOM**. Windows ini functions do **not** support
  UTF-8; Notepad versions that save as UTF-8 without BOM produce scrambled accents.
- A real `wincmd.ini` is ANSI (Windows-1252), CRLF, without BOM, and starts directly with `[Configuration]`.
- **`SetEncoding=äö.do.not.remove`** (bytes `E4 F6` in the file) is written on load. Its non-ASCII characters stop
  Notepad from silently re-saving the file as UTF-8, which it might otherwise do because the file contains UTF-8-encoded
  parts. Do not remove it.
- **Unicode text in an ANSI file** is stored as UTF-8 inside the ANSI file (the "UTF-8-encoded parts"). The change log
  points to a UTF-8 BOM (`EF BB BF`) at the start of such a value, the same marker TC uses for Unicode paths passed
  between instances; the exact rule is not documented (unverified). With the Windows option "Beta: Use Unicode UTF-8 for
  worldwide language support", TC reads both UTF-8 and ANSI values.
- **UTF-16 files** hold Unicode natively; converting `wincmd.ini` (or a redirected file) to UTF-16 LE gives full Unicode
  support, e.g. for names of saved searches and for `[DriveHints]`. TC re-checks whether an ini is UTF-16 when copying
  files, when TC is activated and when it closes.
- `.bar` files may be ANSI or UTF-16 (§7.1). The other small formats have their own rules (§7).

### 2.4 Screen-resolution sections

- **Name**: `[<screen width>x<screen height> (<a>x<b>)]`. On Windows 11 at 200 % scaling (192 DPI) the section was
  **`[3456x1896 (10x20)]`**: the physical screen width, and the pair 10×20; at 96 DPI a section `[1728x1117 (8x16)]` was
  seen; the help's example is `[1024x768 (10x20)]` (depends on DPI; see Appendix A). The pair matches the system-font
  character cell, 8×16 for "small fonts" and 10×20 for "large fonts" (an interpretation; the help does not explain it).
  The 200 % session gave the logical screen as 1728 × 1117; the recorded height 1896 was not reconciled with it.
- `ResolutionSpecific=1` (default) keeps one section per resolution; `ResolutionSpecific=0` keeps everything in
  `[AllResolutions]`.
- **Fallback.** When no section exists for the current resolution, TC reads `[AllResolutions]`; the help: it "will also
  be used for the current fonts when there is no resolution-specific section". Fonts chosen in Options › Font are also
  saved to `[AllResolutions]`.
- **`[Tabstops]`** is used only when no tabstops are stored for the current resolution.
- **Multi-monitor**: the main monitor's section also holds `monitor(x,y,dx,dy;dpi)=x,y,dx,dy` per monitor and DPI; the
  last saved position stays the default. `RestoreSize` decides when TC re-applies a stored size.
- **Content**: main-window placement and dividers, fonts, icon sizes, cursor width, drive-button extra space, thumbnail
  zoom, column tabstops of the panels, Multi-Rename and Synchronize column positions, and the geometry of tool dialogs
  (§5.6).

`[SearchName] 0=.ini` / `1=aaaaa`; `[SearchIn] 0=c:\users`; `[Selection] 0=*.exe`; `[RenameTemplates] 0=[N]`.

**Directory-history entry format** (a used `[RightHistory]`, abbreviated; `<TAB>` is a tab character):

```ini
[RightHistory]
0=c:\windows\
1=c:\
2=c:\Program Files\<TAB>#0
3=c:\<TAB>#00,Program Files
4=c:\Program Files (x86)\<TAB>#0
5=c:\<TAB>#01,Program Files (x86)
…
14=c:\<TAB>#3,users
15=Z:\
16=Z:\Applications\<TAB>#0
17=Z:\<TAB>#00,Applications
18=::{20d04fe0-3aea-1069-a2d8-08002b30309d}|\\My Computer\<TAB>#02,Z:
```

```text
entry   := path [ TAB '#' digits [ ',' name ] ]
path    := file-system path with trailing '\'
         | '::{' GUID '}' '|' displayPath          # virtual folder (here: My Computer)
```

- **Order: `0` is the most recent entry** (inferred, not documented). Evidence: `[LeftHistory] 0=c:\users\` equals the
  saved `[left] path=c:\users\`, and `1=c:\<TAB>#3,users` names exactly the folder of entry 0; in `[RightHistory]`,
  entry 3 (`c:\`, cursor on `Program Files`) is followed in time by entry 2 (`c:\Program Files\`), entry 5 by entry 4,
  entry 18 (My Computer, cursor on `Z:`) by entry 17 (`Z:\`).
- **Suffix.** When a directory is left by Enter or double click on an item, its entry records the **position in the list
  and the name under the cursor**, so that going back puts the cursor on that item again. `#0` without a name = left
  through `[..]` at position 0. Entries without a suffix were left another way (drive change, typed path …). The exact
  grammar of the digit string is not documented: observed `#0`, `#00`, `#01`, `#02`, `#05`, `#2`, `#3` (the positions
  match the item's index in the list; the meaning of an extra leading `0` is unknown). A clone must keep the suffix
  verbatim and strip it (from the TAB on) to get the path.
- Virtual folders are saved only if they have a unique `::{…}` string.
- Thinning hides entries from Alt+Down, but they are still saved (03 › Directory history list).

### 5.9 `[Shortcuts]`, `[ShortcutsWin]`, `[Alias]`

UI: 13 › Misc.: _Redefine hotkeys_; rules: 14 › Redefining hotkeys and aliases; notation: 18 › Hotkey notation
(`[Shortcuts]`).

```ini
[Shortcuts]
CAS+F2=cm_RenameOnly      ; Ctrl+Alt+Shift+F2 runs cm_RenameOnly
CAS+F2_params=            ; optional parameters, a separate key
[ShortcutsWin]
CAS+F2=…                  ; same syntax; these combinations also include the Windows key
```

- Key name: the modifier letters `C` (Ctrl), `A` (Alt), `S` (Shift), in that order, then `+` and the key name. There is
  **no** `W` prefix; Win combinations go into `[ShortcutsWin]`. F13…F24 work when typed in by hand.
- Value: a `cm_` or `em_` command, a command with parameters, or a program. The parameters go in `<hotkey>_params=` (17
  › Commands with parameters).
- `[Alias]`: one key per alias (a word typed on the command line runs a command). The help gives no key layout;
  presumably the same `name=command` + `name_params=` pattern (unverified). The name `RedirectSection` cannot be used as
  an alias.
- `AlternateUserIni` does not move `[Shortcuts]` and `[ShortcutsWin]` (§1.6).

connection details, sync offset, save question) and under Wine (FTP page defaults)._

## 7. Small file formats

### 7.1 `.bar` files

A `.bar` file is an INI file (ANSI or UTF-16) with one section `[Buttonbar]`; entries are numbered from 1 to
`Buttoncount`. Semantics, editor and loading rules: 14 › Button bars (in particular › Semantics of a `.bar` file, which
lists all 26 entries of the shipped default bar).

| Key                      | Meaning                                                                                                                                                                                                                                                                                                                                  |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Buttoncount=N`          | Number of entries, **including** separators and line breaks                                                                                                                                                                                                                                                                              |
| `buttonK=`               | Icon: `file[,index]`. Without `,index` the index is 0; a negative index is a resource ID; `@name.ext` = default icon of extension `.ext`. Environment variables are allowed. `wcmicons.dll` is written **without a path** so that _Set default icon library_ (`[Buttonbar] DefaultLib`) can substitute another library at the same index |
| `cmdK=`                  | Command: program path (optionally with fixed parameters), `cm_…` / `em_…` / command number / comma-separated chain, `cd <path>`, a command with parameters (`OPENTABS …`), or a `.bar` file (subbar). **`-2` = manual line break.** Grammar: 14 › The command language                                                                   |
| `paramK=`                | Parameters (18 › Button and command parameters)                                                                                                                                                                                                                                                                                          |
| `pathK=`                 | Start path; with a `cd` command, the path set in the other panel                                                                                                                                                                                                                                                                         |
| `menuK=`                 | Tooltip. Empty = the command's own description (translated; for `em_` the definition's tooltip, `wcmd_<lang>.ini` before `usercmd.ini`). `\|` = line break, `\|\|` = a literal `\|`, a single space = no tooltip. **There is no `hintK` key.**                                                                                           |
| `iconicK=`               | `0` normal; `1` run minimized (for a `.bar` target: show as menu). Maximized is presumably `-1` (not documented)                                                                                                                                                                                                                         |
| `[options]` `redirect=0` | Optional section: do not copy this bar to the `wincmd.ini` folder when it is not writable (§1.7)                                                                                                                                                                                                                                         |

#### Entry kinds

| Kind              | Stored as                                                                   |
| ----------------- | --------------------------------------------------------------------------- |
| Separator         | `buttonK=` empty and **no** `cmdK` (an `iconicK` may be present)            |
| Line break        | `buttonK=` empty and `cmdK=-2`                                              |
| Program           | `cmdK=<exe path> [fixed params]`, icon usually the program itself           |
| Internal command  | `cmdK=cm_Name` (case-insensitive), icon `wcmicons.dll,<index>`              |
| Subbar / bar menu | `cmdK=<file.bar>` or `OPENBAR…` / `OPENBARMENU`; `iconicK=1` = show as menu |

**Limits:** at most 1000 buttons and 64 KB per file.

**Shipped `DEFAULT.BAR`** (CRLF, 26 entries: 18 buttons and 8 separators; 977 bytes), annotated and abbreviated:

button5=wcmicons.dll,26
cmd5=cm_SrcThumbs

#### Reading and writing rules

- Read `Buttoncount`, then entries 1…N; missing keys are empty. An entry with an empty `buttonK` is a separator unless
  `cmdK=-2`.
- Keep unknown keys and the `[options]` section when rewriting.
- Write the keys of each entry together, in the order of the shipped files (`buttonK`, `cmdK`, `menuK`, `iconicK`;
  `paramK` and `pathK` presumably after `cmdK`), omitting empty ones. The shipped `VERTICAL.BAR`, which carries
  `iconicK=0` on every entry, suggests that TC's editor writes `iconicK` even when it is 0.
- On a write failure, offer to copy the bar to the user profile or to change the file's permissions (§1.5). After a
  successful save, the other running instances reload the bar.

### 7.3 `usercmd.ini` and `wcmd_<lang>.ini`

One section per user command, named after it (14 › User commands (`em_`)):

```ini
[em_recurse]
cmd=em_recurse        ; recursion is detected and blocked
```

- Only `cmd=` is attested. The definition dialog has the fields of a button (command, parameters, start path, icon file
  and index, tooltip, window state), so the other keys presumably mirror `.bar` entries without the number (`button=`,
  `param=`, `path=`, `menu=`, `iconic=`) (unverified).
- If the same `em_` name is in both files, the tooltip comes from `wcmd_<lang>.ini` (when the command is the same or
  empty in one of the files).
- `em_` commands get internal numbers ≥ 10000 at run time; they are not stable identifiers and are not stored.
- Lines longer than 259 characters must survive Rename/Copy in the _Choose command_ dialog.
- The file does not exist in a fresh installation; the dialog's `usercmd.ini` category is then empty.

### 7.4 `.tab` files

INI files written by _Save tabs to file_ / `SAVETABS*` and read by `OPENTABS` / `APPENDTABS` and by a `.tab` path on the
command line (§8.2). Behaviour: 03 › Tab files and storage.

| Section          | Content                                                    |
| ---------------- | ---------------------------------------------------------- |
| `[activetabs]`   | The tabs of one side (the active side when both are saved) |
| `[inactivetabs]` | Only in files with both sides: the other side              |

To build a two-sided file by hand, join two one-sided files and rename one section from `[activetabs]` to
`[inactivetabs]`. The keys inside are presumably those of `[LeftTabs]` (§5.3) plus the active-tab keys of §5.2
(inferred, not documented).

### 7.5 `descript.ion` and `files.bbs`

One comment per line: the file name, a space, the comment, CRLF; names with spaces in double quotes (the 4DOS
convention). Behaviour and limits: 07 › File comments (Ctrl+Z); settings: §4.28.

```text
sel.txt Selection list ü                      ← ANSI cp1252, ü = 0xFC
ro.txt first line\nsecond line<04><C2>        ← multi-line: literal "\n", then bytes 04 C2 before the CRLF
"long name.txt" Comment of a name with spaces
```

The shipped `DESCRIPT.ION` of the program folder uses the same form with upper-case names:

```text
LANGUAGE Additional Totalcmd languages can be found on our addons page on www.ghisler.com
FILTER64 DirectShow filters (64-bit) for use in Lister - Media Player
BLAKEX64.DLL 64-bit DLL to support the fast BLAKE3 hash algorithm, now with multi-threading
```

- **Encoding** by `CommentPreferredFormat` (default 4): plain ANSI, and UTF-16 LE only when a name or comment needs
  characters outside the code page; other values force UTF-16 LE, UTF-16 BE or UTF-8, or use them only when needed. With
  `CopyComments` bit 16 (`CmtOemFont`) `descript.ion` uses the OEM code page.
- **Multi-line comments** are a TC extension in `descript.ion` (lines joined with a literal `\n`, marker bytes
  `0x04 0xC2` before CRLF); `files.bbs` supports multi-line comments natively, always uses the DOS charset and 8.3 names
  only.
- **Length:** up to 4095 characters per comment in `descript.ion`; above 511 the editor warns (count in bold).
- A newly created `descript.ion` gets the **Hidden** attribute.

### 7.6 Selection files

Written by Mark › _Save Selection To File_ (`cm_SaveSelectionToFile`, `…A` ANSI, `…W` Unicode; text command
`SAVESELECTION`, `…A`, `…W`, where no suffix means Unicode on NT systems); read by _Load Selection From File_
(`LOADSELECTION`, ANSI or UTF-16). Behaviour: 03 › Selection files.

```text
<FF FE>dir1\<CR LF>ro.txt<CR LF>sel.txt          ← illustration: UTF-16 LE, no CRLF after the last name
```

- One name per line, **names only** (no path), folders with a trailing `\`, CRLF line ends, **no** line end after the
  last name; UTF-16 LE with BOM (`FF FE`) for the Unicode variant.
- `cm_SaveDetailsToFile` (`…A`, `…W`; with headers `cm_SaveHdrDetailsToFile…`; text command `SAVEDETAILS`) writes all
  shown columns of the selected items; the line format matches the clipboard form _Copy To Clipboard With All Details_,
  `name<TAB>size<TAB>date<TAB>attrs` (07 › Names to the clipboard (Mark menu); for files presumably the same,
  unverified).

### 7.7 List files

| Use                                                                                  | Format                                                                                                                                                                                                                                                       |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `LOADLIST <file>` (button command, also `LOADLIST:<file>` on the command line, §8.2) | One name per line; names without a path are relative to the current directory; wildcards allowed, regular expressions not; file details are read automatically. The panel shows the list like a search result (09 › Feed to listbox)                         |
| `ZIPFROMLIST <archive> <list>`                                                       | One file per line; ANSI, UTF-16 with BOM, or UTF-8 with or without BOM; the list file name may contain Unicode (08 › Packing from a list file (`ZIPFROMLIST`))                                                                                               |

### 7.8 Multi-Rename result log (`renlog.txt`)

_Result list_ opens Lister on `%TEMP%\_tc\renlog.txt`: one line per renamed file, the old full path and the new name,
both quoted, joined by `->` (09 › Start!, collisions, Undo, Result list):

```text
"c:\tc-sandbox\work\photos\IMG_1001.jpg" -> "Photo_110_2025-12-01.jpg"
```

Encoding and line ends were not recorded. Where the undo data (`MultiRenameUndoHistoryLen` runs, usable also after the
tool was closed) is kept is not documented.

### 7.9 Download list (`ftplist.txt`)

Plain text, **ANSI** or **UTF-8 with BOM**; when an added name contains characters outside the current code page, TC
converts the list to UTF-8. One command per line, CRLF. Behaviour and the full command table: 11 › Download list and
HTTP downloads.

```text
line   := [ 'put:' | 'copy:' | 'move:' ] source [ ' -> ' target ]
        | 'sleep:' <ms>
        | 'header: ' <Name> ': ' <value>         # extra HTTP header for the following requests
        | 'copyflags: ' <x>                      # overwrite flags as in the F5 dialog (codes not documented)
source := ftp(s)://… | http(s)://… | local path   # without "put:"/"copy:"/"move:": download, or local copy
```

A line written by _Download later_ for an anonymous FTPS session (no user name in the URL):

```text
ftps://127.0.0.1:2122/.hidden_on_server.txt -> c:\tc-sandbox\B\.hidden_on_server.txt
```

- Proposed file: `ftplist.txt` in the program folder; a name without a path is looked up in the current directory; the
  last name is kept in `[Configuration] ListName`.
- _Net › FTP Download From List..._ processes the list and rewrites the file afterwards.

### 7.10 `.crc` file (Split)

Written by Split File as `<base>.crc` next to the parts `<base>.001`, `<base>.002`, … (08 › The `.crc` file). Three
lines, each ending in CRLF, CRC32 as 8 **upper-case** hex digits (55 bytes for this example):

```text
filename=random_1MB.bin
size=1048576
crc32=A51F2139
```

### 7.11 Checksum files (`.sfv`, `.md5`, `.sha`, `.sha256`, `.bk3` …)

Written by Create checksums, read by Verify (08 › Checksum file format, › Checksum-file formats accepted).

| Form                               | Line                                                                                                                                                                    |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MD5 / SHA / BLAKE3 (written)       | `<lower-case hex digest> *<name>` + CRLF; `*` = binary-mode marker; `<name>` relative to the checksum file's folder, without a path when the checksum file is elsewhere |
| SFV (written; layout not recorded) | `<name> <8 hex digits>`; comment lines start with `;` (de-facto standard)                                                                                               |
| OpenSSL style (accepted)           | `SHA256(name)= <digest>` (also SHA224, SHA384, SHA3-224/256/384/512)                                                                                                    |
| Stream checksum (accepted)         | `<checksum>  -` (two spaces and a dash)                                                                                                                                 |

- Extensions by method: `.sfv` (CRC32), `.md5`, `.sha` (SHA1), `.sha256`, `.bk3` (BLAKE3); the others were not recorded.
  Extra masks recognised by Verify: `ChecksumExtraTypes`.
- Options: _Always use UTF-8 in names_ (`CrcForceUtf8`; otherwise UTF-8 only when a name needs it); _Unix format_
  (`CrcForwardSlashes`: LF and `/` instead of CRLF and `\`).
- Verify accepts ANSI, UTF-8 **with BOM**, and UTF-16 with or without BOM.

### 7.14 Ignore list and log files

## 8. Command-line switches

### 8.1 Syntax

```text
totalcmd64.exe [/o] [/n] [Drive1:\Directory1 [Drive2:\Directory2]] [/i=name.ini] [/f=ftpname.ini]
totalcmd64.exe [/o] [/n] [/L=Drive1:\Directory1] [/R=Drive2:\Directory2] [/i=name.ini] [/f=ftpname.ini]
```

- **Switches are not case-sensitive.**
- The first positional path goes to the left panel, the second to the right one (or source/target with `/S`); `/L=` and
  `/R=` name the panel explicitly.
- Paths with spaces **must** be in double quotes, also after `/L=` and `/R=` (`/R="d:\Letters from Miller"`). Always
  give the full path including the drive.
- The installer has its own switches (01 › Installer command-line parameters).

### 8.2 What a path argument can be

| Form                                                 | Effect                                                                                                      |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `c:\dir`                                             | Directory; an invalid path goes to the nearest valid parent instead of showing `<Read error!>`              |
| `c:\dir\archive.zip`                                 | Opens the archive in the panel (with `/A`: its directory, cursor on the archive)                            |
| `\\server\share\subdir`, `smb://server/share/subdir` | Network share                                                                                               |
| `shell:Folder`, `::{GUID of folder}`                 | Virtual folder                                                                                              |
| `FTPOPEN:stored_ftp_name`                            | Opens a saved FTP connection                                                                                |
| `LOADLIST:path\listfile.txt`                         | Loads a list of files/folders into the panel, like the `LOADLIST0` button command (no error messages; §7.7) |
| `file.tab`                                           | Loads the saved tabs, replacing the current ones (§7.4)                                                     |

### 8.3 Switches

| Switch                            | Effect                                                                                                                                                                           |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/O`                              | If TC is already running, activate it and pass the path(s) to that instance, even when the configuration allows several windows (`OnlyOnce=0`). **Ignored together with `/S=`.** |
| `/O0`                             | Never open a new instance; if none runs, do nothing                                                                                                                              |
| `/O<number>`                      | Like `OnlyOnce=<number>` (positive or negative, §4.2)                                                                                                                            |
| `/O-`                             | Same as `/O-1`                                                                                                                                                                   |
| `/N`                              | Always open a new window, overriding "Allow only 1 copy"                                                                                                                         |
| `/L=<path>`                       | Path for the left panel                                                                                                                                                          |
| `/R=<path>`                       | Path for the right panel                                                                                                                                                         |
| `/S`                              | Read the passed paths as **source/target** instead of left/right (for use with `/O`): `/R=` then means the target panel                                                          |
| `/T`                              | Open the passed directories in new tab(s); also works when TC was not running                                                                                                    |
| `/B`                              | Like `/T`, but in an already running TC the tab opens in the background (not activated)                                                                                          |
| `/A`                              | For an archive path: open its directory and put the cursor on the archive instead of entering it                                                                                 |
| `/P` (no `=`)                     | Open the parent of the passed path and put the cursor on its last part: `/P c:\Windows\System32` → `c:\Windows`, cursor on `System32`                                            |
| `/P=L`, `/P=R`                    | Active panel at start; overrides `ActiveRight=`                                                                                                                                  |
| `/M=<0\|1\|2>`                    | Dark mode: `0` light, `1` automatic (like Windows 10 apps), `2` dark                                                                                                             |
| `/i=name.ini`                     | Use this file instead of `wincmd.ini` (wins over the registry, §1.3)                                                                                                             |
| `/F=ftpname.ini`                  | Use this file instead of `wcx_ftp.ini`                                                                                                                                           |
| `/d=<x>`                          | Delay the start by x seconds (for the Startup folder when other programs start at the same time)                                                                                 |
| `/S=C <file1> <file2>`            | Start Compare by content only, without the main window                                                                                                                           |
| `/S=F[:options] ["start path"]`   | Open Find Files only, without the main window (options §8.4)                                                                                                                     |
| `/S=L[:options] <full file name>` | Start Lister only, on that file (full path required); HTML bookmarks allowed (`c:\test\test.html#bookmark`) (options §8.4)                                                       |
| `/S=P:<port>`                     | Start a parallel or USB port server for the direct cable connection; port names `LPT1` or `USB` (11 › PORT connection (USB or parallel cable))                                   |
| `/S=S <dir1> <dir2>`              | Start Synchronize dirs only, on two paths                                                                                                                                        |
| `/S=S:<SettingsName>`             | … with a saved sync set; `/S=S:=SettingsName` starts the comparison immediately; `/S=S:=` alone compares the passed directories with the last used options                       |
| `/O=<list_name>`                  | Only with `/S=S`: list file for "Only selected (in main window)", e.g. `/O=%F`                                                                                                   |
| `/INSTALLDRIVER`                  | NT-based systems: install the parallel-port driver (so normal users can use the cable connection); must run as administrator                                                     |
| `/INSTALLDRIVERQ`                 | The same, silently                                                                                                                                                               |
| `/REMOVEDRIVER`                   | Remove that driver                                                                                                                                                               |
| `/REMOVEDRIVERQ`                  | The same, silently                                                                                                                                                               |

### 8.4 Sub-options

Appended after a colon, letters concatenated, e.g. `/S=F:S1Lname`, `/S=L:AT1C1250`.

**`/S=F:`** (Find Files)

| Option   | Meaning                                                                                                                                 |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `S<n>`   | Sort results by `1` name, `2` extension, `3` size, `4` date/time; negative = descending. `S*` = take the sort order from the running TC |
| `L<x>`   | **Last** option: load the saved search _x_, e.g. `"/S=F:Lmax 1 day old"`                                                                |
| `L=<x>`  | Last option: load and start immediately                                                                                                 |
| `L==<x>` | Last option: load, start, and feed the results to the listbox when done                                                                 |

**`/S=L:`** (Lister)

| Option    | Meaning                                                                                          |
| --------- | ------------------------------------------------------------------------------------------------ |
| `A`       | ANSI / Windows text                                                                              |
| `S`       | ASCII / DOS text                                                                                 |
| `V`       | Variable-width text                                                                              |
| `F`       | Full screen (like Alt+Enter)                                                                     |
| `T1`…`T8` | View mode: 1 text, 2 binary, 3 hex, 4 multimedia, 5 HTML, 6 Unicode, 7 UTF-8, 8 Explorer preview |
| `C<nr>`   | Code page, e.g. `C1251` (Cyrillic)                                                               |
| `N`       | Auto-detect, but no multimedia or plugins                                                        |
| `P<x>`    | **Last** option: use plugin _x_ (as shown in the Lister title), e.g. `/S=L:Piclview`             |

The same options (without `S=L:`) are accepted by `cm_List` and its variants (17 › Parameters of `cm_` commands).

### 8.5 Interaction rules

```text
start(args):
    if args has /S=<tool>:  run only that tool (no main window); /O is ignored
    elif args has /N:       open a new instance
    else:
        mode = /O-value if /O given else OnlyOnce
        if an instance is running and mode says "reuse":
            send the paths (and /T, /B, /S, /L=, /R=) to it and activate it; exit
        elif /O0 and none running: exit without starting
    apply /i=, /f= before reading any settings
    panels: /L= → left, /R= → right, else positional 1 → left, 2 → right
            (with /S: left ↔ source, right ↔ target)
    /T or /B: open as new tab(s) instead of replacing the current tab
    /P (bare): go to the parent, cursor on the last path part;  /A: archive → its folder
    /P=L|R: active panel;  /M=: dark-mode setting;  /d=: wait first
```

- `/O` with `/S` and `/R=` targets the running instance's **target** panel: `totalcmd64.exe /O /S /R=c:\somepath`.
- What happens with `/L=` together with a positional path is not documented; a clone may let the explicit switch win
  (unverified).
- Paths are passed to the running instance by `WM_COPYDATA` (§8.7); pure ANSI paths as ANSI, each Unicode path prefixed
  with a UTF-8 BOM.
- Standalone Lister, Synchronize and Compare (`/S=L`, `/S=S`, `/S=C`) honour a shortcut's "minimized"/"maximized"
  setting.
- A path passed with `/A` or `/P` is not added to the directory history.
- A restart by `cm_Exit 1` starts the new instance with `/N` and the previous `/i=` and `/f=` (§1.3).

## 9. Environment variables

### 9.1 Where they are expanded

- In most places that take a directory or command: button-bar and Start-menu _Command_, _Start path_ and _Icon file_;
  the command line; the hotlist; `cd`; internal associations; the ignore list; ini values that hold paths
  (`[left] path=`, `PluginBaseDir`, `TreeFileLocation`, `tcmatch`, `ThumbsLocation` …); `cm_Copy /T="…"`.
- **In Parameters fields** `%` starts TC placeholders (`%P`, `%N` …), so an environment variable is written `%|name|`,
  e.g. `%|windir|` or `%|$DESKTOP|` (18 › Single values); `%q` there removes double quotes from `%|envvar|` values.
- **In rename and new-folder masks** they are written `[%VAR%]` (18 › Environment and clipboard).
- **Substrings**, as in cmd.exe: `%name:~5,7%` skips 5 characters and takes 7; negative numbers count from the end.
- **Updates**: `UpdateEnv=3` makes TC take over changed (bit 1) and new (bit 2) system variables while running.
- In `TreeFileLocation` the placeholders `%D%`, `%R%`, `%L%` must be upper case; otherwise TC looks for environment
  variables of those names.
- TC's own variables (§9.3) are exported to the programs it starts, except programs started elevated through `*` (14 ›
  Rules).
- Paths stored by TC itself may keep variables unexpanded, e.g. an auto-installed Lister plugin is registered as
  `%APPDATA%\GHISLER\plugins\wlx\Imagine\Imagine.wlx`.
- Undefined variables: behaviour not documented.

### 9.2 The seven kinds

| #   | Kind                                                                 | Syntax                                                                                                |
| --- | -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 1   | Windows environment variables (`set` in a command prompt lists them) | `%TEMP%`, `%USERNAME%`                                                                                |
| 2   | TC's internal variables                                              | `%COMMANDER_…%` (§9.3)                                                                                |
| 3   | Date and time                                                        | `%$DATE…%` (§9.4)                                                                                     |
| 4   | Clipboard                                                            | `%$CLIPBOARD…%`, `%$CLIPNAME…%` (§9.5)                                                                |
| 5   | Special folders of `ShGetSpecialFolderLocation`                      | `%$NAME%`, at least the first letter upper case (§9.6)                                                |
| 6   | Known folders of `SHGetKnownFolderPath`, by name                     | `%$Name%` (§9.6)                                                                                      |
| 7   | Known folder by GUID                                                 | `%${GUID}%`, e.g. `%${374DE290-123F-4565-9164-39C4925E467B}%` = Downloads, the same as `%$Downloads%` |

### 9.4 `%$DATE%`

| Form                                       | Result                                                                                                                                                                                                                                              |

### 9.7 Expansion order (for a clone)

```text
expand(text, context):
    if context is a Parameters field:  only %|name| forms are environment variables; %X are placeholders
    for each %…% token:

        ${GUID} → known folder by GUID;  $Name → kind 6 list, else kind 5 list;
        name:~s,l → substring of the variable;  otherwise → process environment
```

The order of evaluation between kinds 5 and 6 for names that could fit both is not documented; the lists do not overlap
in spelling.

- `RestoreSize=7` decides when TC re-applies a stored size: after a resolution change (1), a DPI change (2) and a

### 10.3 Round-trip rules for a clone

1. **Locate** the files exactly as in §1.3, and apply `AlternateUserIni` / `RedirectSection` per section (§1.6), reading
   redirections only from the main file.
2. **Detect the encoding** from the BOM: `FF FE` = UTF-16 LE; otherwise ANSI. Never write UTF-8 ini files. Keep the
   encoding of an existing file; keep CRLF.
3. **Read with profile-API semantics**: case-insensitive names, first duplicate wins, one pair of enclosing quotes
   stripped, missing key = documented default (including defaults that refer to other keys).
4. **Write only what changed.** Do not materialise defaults: a real ini contains only touched keys. Update a key in
   place (keep its spelling, position and section order); append new keys at the end of their section; create a section
   at the end of the file.
5. **Preserve everything unknown**: sections, keys, comment-like lines, the `#…` suffixes of history entries,
   `$checksum$` values, `[options]` in `.bar` files.
6. **Keep the markers**: write `SetEncoding=äö.do.not.remove` in ANSI files; perform the `Test=` write check and report
   a read-only file once.
7. **Store Unicode** in UTF-16 files natively; in ANSI files, store non-representable values as UTF-8 with the BOM
   prefix (§2.2, inferred) and accept both forms when reading.
8. **Honour the save conditions** of §10.1 (`Savepath`, `Savepanels`, `SaveCommands`, `SaveHistory`,
   `SaveFrequentlyUsed`, `+4` toggles, `cm_Exit 4`) and write the main-window placement only on Save Position / Save
   Settings.
9. **Resolution sections**: compute the name from the screen size and the system-font cell; fall back to
   `[AllResolutions]`, then to `[Tabstops]` for tabstops.
10. **First start**: copy the default bars to the settings folder when the program folder is not writable, write the
    icon caches, and produce the fresh ini of §1.2.
11. Unchanged settings must produce a byte-identical file (20).
